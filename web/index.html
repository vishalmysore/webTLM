webLTM

A 600 KB model that answers by looping a single block in latent space instead of writing out its reasoning. Turn the depth knob up and it thinks longer — you'll never see a single token of that thinking, only the loop counter ticking and the final digits landing. That's not a UI choice: the architecture has no chain-of-thought channel to expose.

How it's built

prelude
embed digits, run once
→
core
re-run r×, latent state only
↻ ×r
→
coda
read out digits, once

The prelude embeds the input once. The core block then re-reads its own previous state r times — the original embedding is re-injected at every pass so the state doesn't drift as r grows, the trick that lets one set of weights work at any test-time depth. Only the coda's single pass is ever turned into logits. There is no step in between where a token could leak out, because no step in between produces tokens at all — the answer is predicted all at once, not word-by-word.

This is a hobby-scale replica of an idea, not of OpenAI's Astra: Astra's "opaque recurrence" (per TechCrunch's reporting) is an undisclosed, frontier-scale system, and the controversy around it is about chain-of-thought monitorability disappearing at that scale. webLTM is 153K parameters doing addition — small enough to read every line of the loop, on purpose, since the whole point here is to make the mechanism legible rather than opaque.
