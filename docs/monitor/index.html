Visible Thinking

The counterpart to webLTM: a real reasoning model, run entirely in-browser, that never hides a token of its reasoning. DeepSeek-R1-distill models are trained to always emit a <think>...</think> block before answering — every intermediate step streams to your screen exactly as the model produces it, in plain English, not latent vectors you'd need special tooling to inspect.

~7B params ~4.5GB download (one-time, cached after) WebLLM + WebGPU reasoning is text, not a hidden loop

Two ways to make a model "think more"

Same underlying idea — more test-time compute before answering — with opposite transparency properties.

what "thinking" looks like to younothing — a loop counter ticking, no contenteverything — full natural-language reasoning, streamed live

"think more" meansmore loop iterations, ra longer <think> block

model size / first load153K params · 597KB~7B params · ~4.5GB

Legibility isn't free: the model whose reasoning you can read is about 7,700× larger on disk than the one whose reasoning you can't. That trade-off — not just "hidden vs. shown" — is most of what's actually at stake in the opaque-recurrence debate.
