Two ways to make a model think longer

Same underlying question — what happens when you give a model more test-time compute — answered by two small, from-scratch, in-browser demos with opposite transparency properties. One hides every trace of its reasoning by construction; the other can't hide anything if it tried.

opaque recurrence

webLTM

A 153K-parameter recurrent-depth transformer that loops a single block in latent space. No chain-of-thought channel exists in the architecture — you see a loop counter and then the answer, nothing in between.

153K params · 597KB · addition
 visible chain-of-thought

Visible Thinking

DeepSeek-R1-Distill-Qwen-7B, run client-side via WebLLM. Every reasoning token streams to the screen in plain English before the final answer — the opposite design choice, same class of problem.

~7B params · ~4.5GB · same-flavor prompt
Both demos run entirely client-side, no server. Background and results: see the webTLM repo and the write-up on OpenAI Astra's "opaque recurrence" and the recurrent-depth literature these are built from.
